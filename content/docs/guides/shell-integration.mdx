Mori provides shell integration for commands that need to affect the parent
shell environment and for command completion. Parent-shell integration covers
`mori cd`; completions are generated by `mori completions`.

## `mori cd` -- Navigate to a project

`mori cd` looks up a registered project and changes directory to its
local path.

```bash
mori cd namespace/project   # fully qualified
mori cd project             # by name (any namespace)
```

### Why a shell wrapper is needed

A subprocess cannot change the working directory of its parent shell.
The `mori` binary prints the resolved path to stdout; a thin shell
wrapper captures it and calls `builtin cd`.

### Zsh setup

Add the following to `~/.zshrc`:

```zsh
mori() {
  if [[ "$1" == "cd" ]]; then
    shift
    local target
    target=$(command mori cd "$@") || return $?
    builtin cd "$target"
  else
    command mori "$@"
  fi
}
```

### Bash setup

Add the following to `~/.bashrc`:

```bash
mori() {
  if [[ "$1" == "cd" ]]; then
    shift
    local target
    target=$(command mori cd "$@") || return $?
    builtin cd "$target"
  else
    command mori "$@"
  fi
}
```

### Fish setup

Add the following to `~/.config/fish/functions/mori.fish`:

```fish
function mori
    if test (count $argv) -ge 1; and test "$argv[1]" = "cd"
        set -l target (command mori cd $argv[2..])
        or return $status
        builtin cd $target
    else
        command mori $argv
    end
end
```

## How it works

1. The shell function intercepts `mori cd <project>`.
2. It calls `command mori cd <project>` which queries the local
   registry and prints the project's filesystem path to stdout.
3. If the lookup fails, `mori` exits non-zero and the function
   propagates the error via `return $?`.
4. On success, `builtin cd` changes the shell's working directory.

All other `mori` subcommands pass through to the binary unchanged.

## Shell Completions

Mori can print completion scripts for Bash, Zsh, and Fish:

```bash
mori completions bash
mori completions zsh
mori completions fish
```

Some completions, including registered project names and `mori://` references,
query the local registry. Set `MORI_PG_CONNECTION_STRING` in the shell where
the completion script runs.

### Bash

```bash
eval "$(mori completions bash)"
```

### Zsh

```zsh
eval "$(mori completions zsh)"
```

If your Zsh setup manages completions through `fpath`, redirect the generated
script to a file in your completions directory instead.

### Fish

```fish
mori completions fish | source
```

To persist it:

```fish
mori completions fish > ~/.config/fish/completions/mori.fish
```
