This is the field-by-field reference for `mori.dhall`, the project manifest that defines a Mori project's identity, packages, dependencies, and agent configuration.

## Root Fields

| Field | Type | Purpose |
|-------|------|---------|
| `project` | Record | Project identity (name, namespace, type, etc.) |
| `repos` | `List Repo` | Repository references |
| `packages` | `List Package` | Buildable units within the project |
| `bundles` | `List PackageBundle` | Package groupings |
| `dependencies` | `List Text` | Project-level dependency names |
| `apis` | `List Api` | API definitions |
| `agents` | `List AgentHint` | AI agent role configuration |
| `standards` | `List Text` | Standard projects this project follows |
| `docs` | `List DocRef` | Project-level documentation |

## project

The `(namespace, name)` pair forms the unique registry key.

| Field | Type | Notes |
|-------|------|-------|
| `name` | `Text` | Project name, unique within namespace |
| `namespace` | `Text` | Organization namespace (e.g., `"acme"`) |
| `type` | `PackageType` | Primary project type |
| `description` | `Optional Text` | Brief description |
| `language` | `Language` | Primary language |
| `lifecycle` | `Lifecycle` | Project lifecycle stage |
| `domains` | `List Text` | Domain tags |
| `owners` | `List Text` | Team or individual owners |

### Dependency

**Simple form:**

```haskell
Schema.Dependency.ByName "effectful"
```

**Augmented form:**

```haskell
Schema.Dependency.WithAugmentation
  { name = "hasql"
  , extraDocs = [ ... ]
  , localPathOverride = None Text
  }
```

## Validation Rules

Beyond Dhall type-checking, mori applies semantic validation:

1. **Namespace** — must be non-empty and contain no whitespace
2. **No duplicate package names** — package names must be unique within a project
3. **Non-empty dependencies** — all dependency names must be non-empty strings
4. **Bundle integrity** — bundle `primary` must be listed in `packages`
