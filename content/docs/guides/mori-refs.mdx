Canonical cross-project references use the `mori://` URI scheme. They identify
artifacts owned by registered projects: docs, packages, repos, skills,
subagents, APIs, cookbook entries, seihou templates, and OKF bundles.

```text
mori://<namespace>/<name>/<kind-plural>[/<key>][#<anchor>]
```

Compact input forms are accepted for command-line convenience:

```text
<namespace>/<name>[#<kind-singular>:<key>][#<anchor>]
<namespace>/<name>:<package>
```

## Examples

```text
mori://shinzui/streamly
mori://shinzui/streamly/docs/effects-cookbook
mori://shinzui/streamly/docs/effects#pooling
mori://shinzui/streamly/packages/streamly-core
mori://shinzui/streamly/cookbook/postgres-pool
mori://shinzui/streamly/templates/scaffold-app
mori://shinzui/streamly/okf/architecture
mori://shinzui/mori/masterplans/9-agent-plans-extension
mori://shinzui/mori/plans/70-agent-plans-dhall-schema-and-uri-kinds
shinzui/streamly#doc:effects-cookbook
shinzui/streamly#okf:architecture
shinzui/streamly:streamly-core
shinzui/mori#masterplan:9-agent-plans-extension
shinzui/mori#plan:70-agent-plans-dhall-schema-and-uri-kinds
```

For `masterplans/<id>-<slug>` and `plans/<id>-<slug>` (the agent-plans
extension's MasterPlan and ExecPlan kinds), the trailing key is the full
`<id>-<slug>`, not the slug alone. Cross-project dep URIs must use the
exact segment as it appears on disk. See [Agent Plans](/docs/guides/agent-plans).

## Where Refs Work

```bash
mori path mori://shinzui/streamly/packages/streamly-core
mori browse mori://shinzui/streamly
mori registry open-doc mori://shinzui/streamly/docs/effects-cookbook
mori validate --check-refs
```

Refs resolve through the local registry. Register the target project locally
before resolving it.

In Dhall configs, use `DocLocation.Canonical`:

```dhall
location = Schema.DocLocation.Canonical
  "mori://shinzui/streamly/docs/effects-cookbook"
```

Shell completion can complete registered namespaces, projects, artifact kinds,
and artifact keys when the registry connection is available.

See [Canonical Refs](/docs/concepts/canonical-refs) for the full model.
