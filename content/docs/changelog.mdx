## 2026-03-21

### Dynamic extension registry
- **`mori extension define`** — define extension types in a catalog for schema extensions
- **`mori extension list`** — list active extensions
- **`mori extension retire`** — soft-delete an extension (preserves existing data)
- **`mori extension query`** — query extension data across all projects
- Extension data flows through the Project aggregate event-sourcing pipeline
- Stored as JSONB in `mori.project_extensions` with GIN indexing
- Compile-time loader registry maps extension names to typed Haskell loaders (tech-radar is the first adapter)
- `mori help extensions` topic documenting the extension system
- `mori registry show --full` now includes extension data

### Skills and subagents in registry
- Skills and subagents from `mori.dhall` now persist through the full event-sourcing pipeline
- 6 new granular event types: `ProjectSkillAdded`/`Removed`/`Updated`, `ProjectSubagentAdded`/`Removed`/`Updated`
- `mori.skills` and `mori.subagents` database tables with subscription projection
- `mori register` extracts skills/subagents from config and diffs against current state
- `mori registry show --full` displays skills and subagents (text + JSON output)
- Project events now at 22 types (was 11)

## 2026-03-19

### Event-driven daemon registration
- **AutomationRegistration aggregate** — daemon now uses event-driven registration instead of filesystem polling
- `mori automate register`, `deregister`, `update`, `list`, `migrate` commands for managing automation configs
- Daemon subscribes to `automationRegistration` category for live config updates

### Registry open-doc command
- **`mori registry open-doc`** — open project docs in your editor with fzf-based interactive selection
- Supports project and doc selection via fzf with bat-powered previews
- Uses `$EDITOR` / `$VISUAL` for local files, system `open` for URLs

### Claude agent sessions
- **`mori agent claude`** — start a Claude session with full project context, skills, and subagents
- Loads skills and subagents from `~/.config/mori/agents/` and `.mori/agents/` via `--add-dir`
- Context caching for faster subsequent launches

## 2026-03-11

### Skills and subagents schema
- **`skills`** field — define agent skill definitions following the agentskills.io spec
- **`subagents`** field — define specialized AI assistants with provider, model, tools, and permission configuration
- `PermissionMode` type: `Default`, `AcceptEdits`, `DontAsk`, `BypassPermissions`, `Plan`
- Package **`lifecycle`** field — `Active`, `Experimental`, `Deprecated`, `Archived`
- Deprecated lifecycle displayed in pale red in `show` and `registry show` commands
- Skills and subagents integrated into `agent bootstrap` prompts, schema catalog, and `init` scaffold
- See [Schema Reference](/docs/guides/schema-reference) for full field documentation

### Schema upgrade improvements
- `--latest` flag for `mori schema upgrade` to resolve from GitHub
