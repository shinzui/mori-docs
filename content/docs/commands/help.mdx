Show help topics with detailed reference information. Topics are grouped by audience.

```bash
mori help
mori help <topic>
mori help <topic> --width 100
```

## Flags

| Flag | Description |
|------|-------------|
| `--width N` | Wrap output at N columns (default: terminal width, capped at 140 for readability). Affects both direct topic rendering and the fzf preview. |
