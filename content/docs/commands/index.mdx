Complete reference for all `mori` CLI commands, organized by domain.

## Core

| Command | Description |
|---------|-------------|
| [init](/docs/commands/init) | Initialize Mori in a repository |
| [validate](/docs/commands/validate) | Validate the current Mori configuration |
| [show](/docs/commands/show) | Render evaluated Mori metadata |

## Registry

| Command | Description |
|---------|-------------|
| [register](/docs/commands/register) | Register a project in the local registry |
| [registry](/docs/commands/registry) | Query and manage the local registry (list, show, search, docs, reregister, remove, open-doc) |
