Complete reference for all `mori` CLI commands, organized by domain.

## Core

| Command | Description |
|---------|-------------|
| [init](/docs/commands/init) | Initialize Mori in a repository |
| [validate](/docs/commands/validate) | Validate the current Mori configuration |
| [show](/docs/commands/show) | Render evaluated Mori metadata |

## Registry

| Command | Description |
|---------|-------------|
| [register](/docs/commands/register) | Register a project in the local registry |
| [registry](/docs/commands/registry) | Query and manage the local registry, including dependents, OKF bundles, docs, groups, templates, and batch exec |

## Navigation

| Command | Description |
|---------|-------------|
| [cd](/docs/commands/cd) | Navigate to a registered project |
| [path](/docs/commands/path) | Print local path for a project, package, or doc |
| [browse](/docs/commands/browse) | Open a project's repository in the browser |

## Schema

| Command | Description |

## Dependencies

| Command | Description |
|---------|-------------|

## Agents

## Exit Code Policy

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Validation error |
| `2` | Registry unavailable |
| `3` | User abort |
