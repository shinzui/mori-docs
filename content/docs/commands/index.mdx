## Global Flags

All commands support these global flags:

```text
--json       Output in JSON format
--explain    Show decision reasoning
--offline    Disable registry access
--registry   Select registry by name
```

## Exit Code Policy

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Validation error |
| `2` | Registry unavailable |
| `3` | User abort |
