Commands for managing the Mori Dhall schema.

## `mori schema upgrade`

Upgrade `mori.dhall` to the latest schema version.

```bash
mori schema upgrade
mori schema upgrade --latest
```

### Flags

| Flag | Description |
|------|-------------|
| `--latest` | Resolve from the mori-schema GitHub repo instead of the pinned version |

## `mori schema print`

Print schema type reference.

```bash
mori schema print
mori schema print --category types
mori schema print --category records
mori schema print --category automation
```

### Flags

| Flag | Description |
|------|-------------|
| `--category` | Filter by category: `types`, `records`, `automation`, `root` |

## `mori schema migrate`

Check or apply schema migrations to `mori.dhall` or a known extension file (`mori/cookbook.dhall`, `mori/tech-radar.dhall`, `mori.automation.dhall`). The target's file kind is detected by path, and the appropriate migration pipeline is applied — the mk-form rewrite runs first so subsequent field-level migrations operate on a file already in `Schema.<Record>::{…}` form.

```bash
mori schema migrate
mori schema migrate --apply
mori schema migrate --dry-run
mori schema migrate --file path/to/mori.dhall
mori schema migrate --apply --file mori/cookbook.dhall
mori schema migrate --apply --file mori/tech-radar.dhall
```

### Flags

| Flag | Description |
|------|-------------|
| `--apply` | Apply migrations (default: check-only) |
| `--dry-run` | Preview changes without writing |
| `--file` | Target file (default: `mori.dhall`) |

For bulk migration across every project in the local registry (including extension files), use [`mori registry upgrade-schema`](/docs/commands/registry#mori-registry-upgrade-schema). See [Schema Migrations](/docs/guides/schema-migrations) for per-migration details and the `rewrite-to-mk-form` migration.
