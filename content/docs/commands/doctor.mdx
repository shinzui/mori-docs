Check system health.

```bash
mori doctor
mori doctor --ingest
```

By default, `mori doctor` runs baseline database checks:

- **PostgreSQL connection** — verifies database connectivity via `MORI_PG_CONNECTION_STRING`
- **Legacy MessageDB compatibility** — verifies the `message_store` schema is present

The compatibility check is still part of the current CLI because migration and
mixed-runtime deployments can read legacy MessageDB history. The current event
runtime is the keiro/kiroku stack; see [Event Sourcing](/docs/concepts/event-sourcing)
and [`mori history`](/docs/commands/history).

`mori doctor --ingest` skips the baseline checks and audits repository ingest
health from `mori.repository_ingest_status`. It exits `2` when any repo is stuck
after repeated failures or no successful ingest in the health window, which makes
it suitable for cron and CI monitoring.
