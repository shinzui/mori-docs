Check system health.

```bash
mori doctor
```

Runs the following checks:

- **PostgreSQL connection** — verifies database connectivity via `MORI_PG_CONNECTION_STRING`
- **MessageDB installation** — verifies the MessageDB event store schema is present

Displays version information and reports pass/fail status for each check.
