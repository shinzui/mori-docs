Open a registered project's repository in the browser.

```bash
mori browse <project>
mori browse <project> --repo <name>
mori browse <project:package>
```

Resolves the project from the local registry, looks up its configured repositories,
and opens the URL in the system browser via `open`.

## Package-Qualified Syntax

Use colon syntax to target a specific package's repository:

```bash
mori browse hasql:hasql-pool
```

When a package name is provided, mori selects the matching repository if one exists,
otherwise falls back to the first repository.

## Flags

| Flag | Description |
|------|-------------|
| `--repo` | Select a specific repository by name (overrides package matching) |

## Repository Resolution

1. If `--repo` is specified, uses that exact repository name
2. If `project:package` syntax is used, matches repository name to package name
3. Otherwise, uses the first configured repository

URLs are constructed from the project's repository metadata (GitHub, GitLab, or raw git URL).

See [Navigation guide](/docs/guides/navigation) for usage patterns with `cd`, `path`, and shell integration tips.
