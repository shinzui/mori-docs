Commands for working with project dependencies.

## `mori deps resolve`

Resolve dependency metadata.

```bash
mori deps resolve
mori deps resolve --explain
```

## `mori deps explain`

Explain how a dependency was resolved. With package-qualified names, shows only
the target package.

```bash
mori deps explain streamly
mori deps explain hasql:hasql-pool
```

## `mori deps locate`

Locate a dependency on the local filesystem. Supports package-qualified names
with colon syntax (`project:package`).

```bash
mori deps locate streamly
mori deps locate streamly --json
mori deps locate hasql:hasql-pool
mori deps locate shinzui/hasql:hasql-pool
```

### Output

- Filesystem path to registered project
- Documentation paths
- Package bundle info (if applicable)

### Resolution Order

1. Local registry
2. Global registry (if online)
3. Not found

## `mori deps tree`

Show transitive dependency tree.

```bash
mori deps tree
mori deps tree --max-depth 2
mori deps tree --project @acme/payments
mori deps tree --json
```

### Flags

| Flag | Description |
|------|-------------|
| `--max-depth` | Maximum depth to display (default: unlimited) |
| `--project` | Show tree for a specific project |
| `--json` | JSON output |
