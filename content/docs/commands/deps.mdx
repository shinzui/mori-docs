Commands for working with project dependencies.

## `mori deps resolve`

Resolve dependency metadata.

```bash
mori deps resolve
mori deps resolve --explain
```

## `mori deps explain`

Explain how a dependency was resolved. With package-qualified names, shows only
the target package.

```bash
mori deps explain streamly
mori deps explain hasql:hasql-pool
```

## `mori deps locate`

Locate a dependency on the local filesystem. Supports package-qualified names
with colon syntax (`project:package`).

```bash
mori deps locate streamly
mori deps locate streamly --json
mori deps locate hasql:hasql-pool
mori deps locate shinzui/hasql:hasql-pool
```

### Output

- Filesystem path to registered project
- Documentation paths
- Package bundle info (if applicable)

### Resolution Order

1. Local registry
2. Global registry (if online)
3. Not found

## `mori deps tree`

Show transitive dependency tree.

```bash
mori deps tree
mori deps tree acme/payments --depth 5
mori deps tree --scope regular
mori deps tree --scope regular,test
mori deps tree --scope all
mori deps tree --json
```

### Flags

| Flag | Description |
|------|-------------|
| `--depth` | Maximum depth to display (default: `3`) |
| project argument | Optional `namespace/name`; when omitted, mori reads the current directory's `mori.dhall` |
| `--scope` | Filter package-level dependencies by [scope](/docs/schema-guide#dependency-scope) (`regular`, `dev`, `test`, `build`), comma-separated combinations, or `all` |
| `--json` | JSON output |

### Scope display

Each package-level dependency renders with a trailing scope tag in `mori
registry show`, `mori show --full`, and `mori deps tree`:

```
streamly-core
tasty           [test]
hspec-discover  [build]
hlint           [dev]
```

`regular`-scoped deps display without a tag. See [Dependency
Scope](/docs/schema-guide#dependency-scope) in the schema guide for the
declaration form.
