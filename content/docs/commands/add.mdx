Authoring commands for adding project metadata interactively.

## `mori add project`

Add project metadata fields interactively.

```bash
mori add project
```

## `mori add package`

Add a package definition.

```bash
mori add package <name>
```

## `mori add dependency`

Add a dependency using registry metadata.

```bash
mori add dependency <name>
```

## `mori add api`

Add an API definition.

```bash
mori add api <name>
```

## `mori add standard`

Declare adherence to a standard project.

```bash
mori add standard backend-architecture
```
