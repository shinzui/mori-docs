Manage Claude Code skills and subagents — reusable prompt modules distributed
via the [mori-kit](https://github.com/shinzui/mori-kit) repository. The kit
system clones mori-kit (cached at `~/.cache/mori/kit/`), reads a `kit.json`
manifest, and installs items into your Claude Code agent directories.

## `mori kit list`

List available skills and subagents from the cached or refreshed kit catalog.

```bash
mori kit list
```

## `mori kit install`

Install a skill or subagent.

```bash
mori kit install <NAME>
mori kit install <NAME> --project
```

### Flags

| Flag | Description |
|------|-------------|
| `--project` | Install to project scope (`.mori/agents/`) instead of user scope |

By default, skills and subagents are installed to the user-level directory
(`~/.config/mori/agents/`). Use `--project` to install to the current
project's `.mori/agents/` directory instead.

## `mori kit update`

Update installed skills and subagents.

```bash
mori kit update
mori kit update <NAME>
```

Without a name argument, updates all installed items.

## `mori kit uninstall`

Uninstall a skill or subagent.

```bash
mori kit uninstall <NAME>
mori kit uninstall <NAME> --project
```

### Flags

| Flag | Description |
|------|-------------|
| `--project` | Uninstall from project scope (`.mori/agents/`) |

## `mori kit status`

```bash
mori kit status
mori kit status --json
```

Conditions compose with `+`: `outdated`, `changed-upstream`, `modified`, `edits-unknown`,
`delisted`, `refused` and `unknown`. A row with none reads `up-to-date`. Local `modified` files
are skipped by update unless `--force` is supplied. The comparison uses the installed sidecar
and cached manifest; see [Kit](/docs/guides/kit) for meanings and cache diagnostics.

## Interactive install, scopes and JSON

`mori kit install` without NAME refreshes the catalog and opens an fzf picker when a terminal
and fzf are available. Cancelling installs nothing; otherwise supply NAME. Project scope resolves
the nearest ancestor with `mori.dhall`, `.mori` or `.git`, and uses its `.mori/agents/.claude`
directory. The same root is used by status, update, uninstall and agent sessions.

List, status and update accept `--json`, producing one versioned document on stdout and warnings
on stderr. `mori kit update NAME --force` overwrites local edits.

## Relationship to Agent Sessions

Installed skills and subagents are automatically loaded into Claude sessions
started via `mori agent claude`. User-level and project-level items are
both included via `--add-dir` flags.

See [Kit guide](/docs/guides/kit) for the full documentation and
[Agent Sessions](/docs/guides/agent-sessions) for how sessions load kit items.
