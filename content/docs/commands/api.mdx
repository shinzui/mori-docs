Commands for API analysis and planning.

## `mori api graph`

Render API dependency graph.

```bash
mori api graph
```

## `mori api impact`

Show impact of API changes.

```bash
mori api impact <api>
```

## `mori api update-plan`

Generate an update plan.

```bash
mori api update-plan <api>
```
