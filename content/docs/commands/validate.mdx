Validate the current Mori configuration.

```bash
mori validate
mori validate --check-deps
mori validate --check-refs
```

## Checks

- Dhall type-checking
- Schema compatibility
- Internal reference integrity
- `apiSource.project` must appear in project-level `dependencies`

### `--check-deps`

Validate declared dependencies against the local registry. Requires a database
connection.

```bash
mori validate --check-deps
```

This checks that all dependency names (both project-level and package-level)
resolve to registered projects in the local registry.

### `--check-refs`

Walk every [canonical `mori://` ref](/docs/concepts/canonical-refs) stored in
the project's config and extension files, parse each one, and resolve it
through the local registry. Requires a database connection.

```bash
mori validate --check-refs
```

The check covers:

- `mori.dhall` — project-level `docs`, per-package `docs`, augmented
  `Dependency.extraDocs`
- `mori/cookbook.dhall` — cookbook entries
- `mori/checklist.dhall` — checklist source docs and per-item `docs`

Output is grouped by source with a per-ref `✓ / ✗ / ⚠` indicator. Tags name
the source location (e.g. `Project.docs[3] <key>`,
`Package.foo.docs[1] <key>`, `Dependency.streamly.extraDocs[0] <key>`,
`Cookbook.entries[i] <key>`, `Checklist.checks[i].sourceDoc <key>`,
`Checklist.checks[i].items[j].docs[k] <checklist-key>/<item-key>`).

`okf` refs are checked at both the bundle and the nested
`…/concepts/<segment>` grain. A concept ref that matches more than one indexed
concept fails with an ambiguity message naming the candidates — the bundle has
duplicate document IDs, so address one by its concept path instead.

Exit codes:

| Code | Meaning |
|------|---------|
| `0`  | Every canonical ref resolved |
| `1`  | At least one ref failed (missing project, missing artifact key, ambiguous concept) |

A malformed ref carrying a nested sub-key on a kind with no nested grammar
produces a ⚠ warning but does not fail the check.

## Flags

| Flag | Description |
|------|-------------|
| `--check-deps` | Validate dependencies against the local registry |
| `--check-refs` | Validate canonical `mori://` refs in the config and extension files |

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Valid |
| `1` | Invalid |
