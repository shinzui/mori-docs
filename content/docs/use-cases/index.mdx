These scenarios start with a person's goal and follow the path through Mori's
declared project data, registry, and automation. Each page opens with an SVG
showing the trigger, the main steps, the outcome, and what remains to be built.
The steps distinguish capabilities that exist today from planned or discovered
work. A use case marked **draft** can still contain delivered features.

The source bundle is `mori://shinzui/mori/okf/use-cases`. Its seven concepts
are `UC-1` through `UC-7`; these pages summarize the source and link to the
relevant public guides.

The source status describes the use case concept. The delivery notes on each
page describe its individual features, including gaps that remain even when
the main flow works.
